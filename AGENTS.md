# Project information

- This is a static site deployed via GitHub Pages (`CNAME`: theinternetportalsofmeaninglessness.com). There is no package manager, build step, or committed test suite.
- Layout: `index.html` at the root; `assets/css/style.css`, `assets/js/*.js`, `assets/img/` (all svg/png/jpg/gif, incl. the OG image), `assets/fonts/`, `assets/video/`, `assets/audio/`, `assets/favicon/`. Paths in `index.html` and in JS (e.g. `footer-fine-print.js`) are relative to the root (`assets/img/...`); `url()` paths in `style.css` are relative to `assets/css/` (`../img/...`, `../fonts/...`).
- `404.html` (served by GitHub Pages for any unknown URL) just redirects to `/` via `location.replace` with a meta-refresh fallback; it's `noindex`. Its paths must be root-absolute (`/...`) since it can be served at any depth.
- `robots.txt` and `sitemap.xml` live at the root; update `<lastmod>` in the sitemap when content changes meaningfully.
- Serve locally from this directory with `python3 -m http.server 8000 --bind 127.0.0.1`.
- Verify layout changes in a browser at desktop, tablet, and mobile widths, including 1024px, 768px, 576px, and 320px. Check panel order, viewport-height fit, absence of page overflow, and internal panel scrolling with long content.
- Above 56rem the page uses a fixed `100dvh` height with a `100vh` fallback. Keep grid row minimums at zero so panels can shrink; overflowing content should scroll inside panels instead of expanding the page.
- At 56rem and below the page scrolls vertically: every `.row .panel` is forced to `aspect-ratio: 1 / 1` (at least square) and grid rows are `auto`.
- `#footer-fine-print` glyph row is populated by `footer-fine-print.js` (random `ipom-img-footerfineprint-c1..c8.svg` per slot, count derived from available width, minimum 2 per side; on very narrow screens the script shrinks the whole row via `--fine-print-scale` so 2 + centre + 2 always fit).
- `#ticker-display` content lives in `ticker-display.js` (canvas, `ResizeObserver`-driven, 30fps rAF loop; respects `prefers-reduced-motion`).
- `#glyph-deterioration` is layered: striped panel background (CSS), `.deterioration-plate` (`#3d0f0c`, angular `clip-path` in `--plate-shape`), `.deterioration-body` (main glyph as a CSS-masked div so it can recolor on hover, plus 4 lines of U+E000 from the `Portal Glyph` font: `portal-glyph.woff2/woff/ttf`), and a transparent particle canvas on top driven by `glyph-deterioration.js` (grid-snapped squares, edge/corner-biased, denser on hover; static frame under `prefers-reduced-motion`).
- `#main-event` centre graphic is one canvas in `.main-event-center` driven by `main-event-center.js`: 2×8 outlined boxes positioned from the title's measured rect (box-bottom→title-top gap equals title-bottom→panel-bottom gap), one waving strand anchored inside each box, and the sparkle emitter adapted from the user's particle sketch (60Hz fixed step, paused off-screen, static prewarmed frame under `prefers-reduced-motion`). Debug: `window.__mainEventCenterDebug()`.
- `#biology` is a size container (`container: biology`): side-by-side columns when wide, stacked via `@container biology (aspect-ratio < 2)` on square panels. Left `.biology-media` holds a looping muted `<video class="biology-video">` (`assets/video/js-ipom-website-biological-organicsynthesis.mp4`, H.264, `object-fit: cover`; paused under reduced motion by `biology-smoke.js`) under the `classifcation3` overlay; and `.biology-specimen` (right box, below `classifcation2`, which sits inside the box) holds the smoke canvas from `biology-smoke.js` (long filaments defined across the box: braiding travelling waves inside a plume envelope plus a trochoid curl that loops when its strength > 1; variable-width `#acdefb` core with `#0167a2` outline and speckle, tails thin to blue lines, plus thin grainy `#0167a2` lines; strands render to an offscreen layer composited as a breathing `ctx.filter` blur haze + soft smoke puffs shed mostly from tails + the strands at 0.6px blur (haze skipped if `ctx.filter` unsupported); 60Hz fixed step, paused off-screen, static prewarmed frame under `prefers-reduced-motion`; debug `window.__biologySmokeDebug()`).
- `#warped-lines` (CSS only, size container `warped`): `.warped-slider` crossfades the three `js-ipom-website-warpedlines*.svg` files (18s cycle: 3s hold / 3s fade via negative `animation-delay`). Each is wrapped in an outer `<svg preserveAspectRatio="none"><image>` because an `<img>` can't override the file's own aspect-ratio "meet" — that's what makes them stretch. Calibration strip shows one SVG, or both via `@container warped (aspect-ratio >= 2)`.
- `#welcome` is a fixed overlay (z-index 1000, 90% `#acdefb` + backdrop blur) shown on load; `body.welcome-open` locks scroll. `welcome.js`: title click n performs n random letter-pair swaps (capped at letter count); credit line toggles random per-letter `scaleY(-1)` flips; "enter site" fades the layer, hides it, and plays `#welcome-audio` (`assets/audio/ipom.mp3`, loops). Fonts: Adobe Typekit `velzyland` (kit `zzf1dix`) and Font Awesome 6.5.2 brands via cdnjs with SRI. Adobe Fonts only serve on domains allowed in the kit settings.
- Cursor: `--cursor-diamonds` (default) and `--cursor-pointer` (clickables, `#ada6b3`; default is `#a798b3`) in `:root` are inline SVG data-URI cursors (30px, hotspot 15 15); use `var(--cursor-pointer)` instead of `cursor: pointer` for new clickable elements. `cursor-trail.js` draws falling pixie dust on a fixed `.cursor-trail` canvas (z-index 2000, pointer-events none); skipped for touch (`pointer: fine` only) and reduced motion; rAF stops when idle.
- Layout colors and spacing are CSS custom properties in `:root`. Responsive breakpoints are 56rem and 36rem.
- The header SVG switches `viewBox` width per breakpoint in `script.js` (`LAYOUTS`: 2730.67 desktop, 2048 tablet, 1288 mobile) and shifts each `[data-strip-group]` along x. `--strip-height` in `style.css` must use the same width per breakpoint (height = 100vw * 90 / viewWidth) or `preserveAspectRatio="meet"` letterboxes the strip.
